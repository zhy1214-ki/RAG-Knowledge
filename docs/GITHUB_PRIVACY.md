# 发布副本隐私说明

本副本使用独立Git目录和全新提交历史；不继承原仓库作者/提交者/标签邮箱或原始提交对象。首次本地提交只使用用户已明确确认的GitHub noreply邮箱，配置仅限本仓库，不修改全局身份。

原始历史仍留在原仓库。本副本不会删除或匿名化原始历史，也不把新仓库伪称为早期开发过程。原仓库历史不在本次发布范围内。

Private仓库只限制访问范围。获得权限者仍能读取源码和新提交元数据，并可保留克隆；它不是秘密保险库，也不能保证撤回副本。未来真实运行数据、密钥或聊天不得加入Git。

真实API Key和密码只能在本机后端配置，不能进入浏览器、镜像或文档。只分享经过内容审核的源码、配置占位符和合成样例。具体旧审批标识、原始审计及个人设备路径不作为发布附件。

本次安全扫描有模式识别边界，不保证发现所有未知格式秘密。后续新增文件和提交必须重新审核，不能只依赖.gitignore，更不能自动执行git add .或推送全部本地引用。
