# 本地材料与源码分发边界

发布文档中标为“本地专用”的材料没有随Git源码分发，不是下载链接。本页不列出原始审批ID、个人设备路径、账号ID或账本内容。

| 类别 | 本副本处理 |
|---|---|
| 原始验收及进度记录 | 只保留已审核文档中的范围说明，不导入原始审计 |
| 模型请求与费用日志 | 排除；摘要不代表新环境额度或实时账单 |
| 截图、录屏及部署回滚包 | 排除；不能把缺失附件冒称已上传 |
| Git历史、旧源码归档、bundle及发布审查报告 | 排除；本仓库采用全新历史 |
| 数据库、Milvus、上传文档、聊天及密钥 | 排除；不属于发布源码 |
| 合成政策测试样例 | 保留README引用的两份PDF及一份DOCX，均经过内容检查 |

缺失的原始材料不会通过创建同名空文件或上传运行目录来“补齐”。相关历史测试摘要是有范围的既有证据，不是本次重新执行的记录。需要额外展示时另行脱敏和授权。
