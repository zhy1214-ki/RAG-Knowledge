# 系统使用说明

> GitHub副本说明：标为“本地专用”的原始证据未纳入Git，不是可下载附件。分类及存在性见[本地材料索引](../LOCAL_EVIDENCE_INDEX.md)；不复制原始审计或用户数据来补齐链接。

适用V1.0“知序”；当前8080新版部署/Mock模式依据M6.6历史记录。
本章说明用户使用方式，M7没有实际登录、上传、提问或删除。
涉及新增数据的步骤仅供后续获准的专用演示资源使用；只读展示可直接查看已有授权记录与截图。

## 1. 进入与模式确认

入口http://127.0.0.1:8080。首次进入未登录时跳到/login。
没有内置管理员账号或默认口令；已有用户自行保管凭据。
系统仅保存密码散列，无法从数据库“读回原密码”，也没有密码找回功能。

材料里的m66_demo只是一轮浏览器Mock夹具的合成用户名，不能当成实际系统登录账号。
登录时不要录制输入的密码、浏览器存储或认证响应。
账号不存在时，新注册属于数据写入，须在获准的演示资源中操作。

准备互动演示前，可查看/api/health的公开模式字段，确认model_backend=mock。
聊天页还应显示“离线演示模式”。若模式未确认，不上传或提问；
不得借演示之名重新调用真实模型。M7本身没有访问健康接口或改变模式。

## 2. 登录与首页

输入自己已有的用户名和密码，点击登录；错误会以安全提示显示。
首页展示当前用户的知识库、已上传文档和问答会话数量，并可进入最近知识库/会话。
“—”表示尚未加载或请求失败，不是数量为0；刷新只重新查询，不创建数据。

## 3. 知识库管理

列表采用卡片，支持按名称/描述搜索；文档、编辑和删除入口位于卡片下方。
获准新增时，点击“创建知识库”，填名称和可选描述后保存；
同一用户下名称不能重复，不同用户的同名知识库独立。

点击“文档”进入该知识库文档页。编辑只改名称/描述，不改变文件或向量内容。
删除知识库会清理其文档、索引、文件和关联会话/消息，须确认影响范围；
只读演示不要点击确认删除。

## 4. 文档上传及状态

选择正确知识库后，可拖放或选择一份非空PDF、DOCX、TXT、Markdown；
单份默认不超过20MiB，页面标注20MB；TXT/MD采用UTF-8。
扫描PDF需预先OCR，本系统不提供OCR服务。

上传时显示实际传输进度或不定进度；按钮禁用，避免重复上传。
服务返回202后仍需等待后台处理，进度达到indexed才参与检索。

| 状态文案 | 含义与操作 |
|---|---|
| 等待处理 | uploaded，文件保存完成 |
| 解析与索引中 | processing，10/40等为阶段进度，不是上传字节比例 |
| 已索引 | indexed，允许参与检索 |
| 处理失败 | failed，按安全原因检查文件或联系维护者 |
| 等待重试删除 | deleting，外部清理未完成；恢复后可按授权重试删除 |

上传进度（本地专用材料，不随发布源码分发）、
文档列表（本地专用材料，不随发布源码分发）。
文档列表可按名称/状态筛选。前端按需GET轮询，离开页面会停止计时器。
上传失败或结果不确定时暂停再次上传，先刷新查看记录，不盲目重复操作。
后台失败不会把先前202改成失败HTTP；务必查看文档状态。

## 5. AI智能问答与引用

在文档页点击“去知识库提问”，或进入AI问答选择知识库。
输入具体问题，点击发送或Ctrl+Enter。输入法组合输入期间不会触发快捷提交。
生成中显示检索/回答状态并禁用重复发送，完成后展示用户消息和AI回答。

当前Mock回答会明确带“离线演示”，使用检索片段生成展示文本，
不是临时偷偷调用Qwen。没有通过检索的来源时会明确说明证据不足；
可检查知识库选择、文档是否indexed以及问题与原文用词是否相关。

来源可展开查看编号、文件名、文档ID和原文片段。
PDF只展示真实来源页码；Word/TXT/MD不推测页码。
回答可显示Markdown及代码块；代码复制由浏览器权限控制，不自动执行代码。
问答与来源截图（本地专用材料，不随发布源码分发）。

截图中PDF第3页来自合成引用夹具，证明UI显示方式；
不能将它单独当成真实PDF解析结果。真实解析和引用规则由源码及历史设施测试支持。

服务失败/超时后先“查看会话记录”，该动作只GET，不自动重发或解锁原请求。
确认结果以前不要再按发送；来源内容也是不可信资料，使用者仍需核对事实。
系统并不提供跨标签页请求幂等或对所有模型错误的自动恢复。

## 6. 会话历史

进入会话历史，选中左侧记录即可预览问题、回答及来源快照，
可搜索会话或知识库，点击“继续问答”恢复上下文。
历史截图（本地专用材料，不随发布源码分发）。

只有当前用户自己的会话可被读取。删除单份文档后旧引用快照仍保留；
删除会话或知识库会清除相应消息，不能把删文档当成彻底清除历史正文。
本轮不执行这些删除操作。

## 7. 后续获准互动演示的合成样例

可在专用演示账号中新建测试知识库，上传项目samples/real-rag-policy.txt。
它只包含虚构的17天退还政策，不含个人或业务资料。
问题示例：What is the return period in the RAG acceptance policy? Give the number of days and cite the source.

当前Mock模式预期展示检索片段和[1]，不是宣称重新生成历史Qwen答案。

M7只提供说明，不在当前数据库中补造演示数据。
缺少账号或记录时，使用本包截图和已存验收摘要讲解，不临时创建真实模型验收环境。

## 8. 常见问题

- 没有文档或结果：核对当前知识库和indexed状态，调整问题；不要把空结果称为模型故障。
- Word没有页码：格式缺乏稳定提取页码，属于预期设计。
- 解析失败：检查是否扫描PDF、编码、损坏文件或规模限制；系统不会自动OCR。
- 登录过期：重新登录自己的账号，不分享令牌。
- 页面仍旧：手动刷新或用新的浏览器上下文；不要自行重建服务。
- 没有默认密码：本系统不设公开演示口令；联系账号持有人，勿将密码写入答辩材料。
